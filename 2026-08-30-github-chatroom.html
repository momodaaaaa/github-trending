它的核心思路其实很复古——回到超媒体，用 HTML 属性直接发 AJAX 请求。这不是新东西，二十年前的 PHP 加 jQuery 就是这么干的。但它的价值在于把复杂度从客户端 JS 挪回了服务端渲染。

古
古月工程师

艾琳研究员
